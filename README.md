# Практическая работа №1 (Тема 2) — Анимация на чистом CSS

**Автор:** Харланович Алексей, ПИУКИС-23

## Описание
Сверстана анимация «Анимированное дерево» по методическим указаниям
«Простая анимация на чистом CSS». Дерево «вырастает» на глазах:
сначала появляются листья, затем распускаются цветы, а из-под цветков
вырастают ножки с плодами.

## Файлы
- `index.html` — разметка страницы и дерева;
- `style.css` — стили и анимации;
- `README.md` — описание проекта.

## Что реализовано
- **HTML-разметка дерева**: холст `.canvas`, ствол `.trunk`, 8 веток `.branch`,
  листья `.leaf`, цветы `.flower`, плоды `.fruit` с ножкой `.stem` внутри.
- **Нативная CSS-анимация** через `@keyframes`:
  - `leaf-odd-grow` — рост нечётных листьев;
  - `leaf-even-grow` — рост чётных листьев с поворотом;
  - `flower-bloom` — распускание цветов;
  - `fruit-appear-odd` / `fruit-appear-even` — появление плодов на ножке;
  - `tree-sway` — покачивание всего дерева (только при наведении).
- **Свойства анимации**: `animation-name`, `animation-duration`,
  `animation-delay`, `animation-fill-mode: both`.
- **Каскад появления**: листья → цветы → плоды (задержки 2.5s–6s).
- **Компенсация наклона веток** через `rotate(60deg)` / `rotate(-60deg)` —
  плоды свисают вертикально вниз, ножка уходит вверх к цветку.
- **Псевдоэлементы** `::before` / `::after` для лепестков цветка.
- **Адаптив** для мобильных экранов через `@media (max-width: 600px)`.
